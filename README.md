# Reversi

Encadre les pions de l'ordinateur pour les retourner à ta couleur. Celui qui a le plus de pions à la fin gagne.

Tu as les noirs et commences. Pose un pion pour encadrer ceux de l'ordinateur : ils se retournent. Sans coup possible, on passe. Trois niveaux, du débutant au stratège.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Reversi → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
